#############
Moritz Manual
#############

Moritz is a 3D application for people who know 3ds Max. It is built on Blender 5.3: files are
ordinary ``.blend`` files that open in Blender and the other way round, and everything Blender can
do, Moritz can do. What changes is the way you work: a Command Panel with Create, Modify and
Utilities, Edit Poly with Max's sub-object levels and tools, parametric objects, a quad menu,
Max's names and keys.

This manual covers what Moritz does differently. For everything it leaves as it is (rendering,
materials, animation, sculpting, Geometry Nodes, the Python API), each page links to
:blender:`Blender's manual <index.html>`.
