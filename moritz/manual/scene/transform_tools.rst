###############
Transform Tools
###############

Transform Type-In
=================

**F12** puts the cursor into the X / Y / Z fields: absolute or offset values for Move, Rotate and
Scale, for objects and sub-objects.

Pivot
=====

**Affect Pivot Only** (Insert), **Center to Object**, **Align to World**, **Reset XForm** (Blender's
Apply > All Transforms): in the quad menu, Object > Transform and the Utilities tab.

Utilities tab
=============

Align
   Pick a target in the viewport; align minimum, center, pivot or maximum per axis, the
   orientation and the scale. **Pivot only** moves the pivot instead of the object.

Array
   1D, 2D or 3D; incremental or total move, rotate and scale; copies, instances or references.

Spacing Tool
   Objects along the active curve, by count or spacing, with Follow.

Object Paint
   Paints copies of objects onto the grid, a surface or the selection, with spacing, scatter,
   rotation and scale.

Clone
=====

**Ctrl+V** or **Shift+drag** (also on a gizmo arrow or plane): Copy, Instance or Reference, and the
number of copies. Instances and references share the mesh and the original's modifier stack.
