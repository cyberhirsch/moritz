###################
Coming from 3ds Max
###################

Where the things you know from 3ds Max are in Moritz. Keys are for the **Moritz** keymap; the Max
keymap is one click away in **Preferences > Keymap**.

Getting around
==============

.. list-table::
   :header-rows: 1
   :widths: 40 60

   * - Max
     - Moritz
   * - Pan, orbit, zoom
     - Middle mouse, Alt+middle mouse, Ctrl+Alt+middle mouse, or the wheel. Preferences > Keymap
       > Maya Navigation for Alt+left / middle / right mouse.
   * - Top / Front / Left / Perspective / Camera
     - T / F / L / P / C, or the numpad (7 / 1 / 3 / 5 / 0)
   * - Zoom Extents Selected / All
     - Z / Ctrl+Shift+Z
   * - Maximize Viewport
     - Alt+W, or Space, on the viewport under the mouse
   * - Undo / Redo Viewport
     - Shift+Z / Shift+Y
   * - Quad menu
     - Right-click (see :doc:`/interface/quad_menu`)
   * - Global Search
     - X

Selecting
=========

.. list-table::
   :header-rows: 1
   :widths: 40 60

   * - Max
     - Moritz
   * - Click, Ctrl+click adds, Alt+click removes
     - The same
   * - Window / Crossing
     - Drag left to right: window. Right to left: crossing.
   * - Rectangle / Circle / Lasso region
     - Q cycles the shape
   * - Selection preview
     - Hover highlight, on by default
   * - Select by Name
     - H
   * - Named Selection Sets
     - Select menu, for objects and sub-objects
   * - Select Children
     - Double-click
   * - Hide / Unhide, Isolate
     - Alt+H, Alt+U, Alt+Q
   * - Freeze
     - Quad menu > Freeze Selection; frozen objects draw gray

Transforming
============

.. list-table::
   :header-rows: 1
   :widths: 40 60

   * - Max
     - Moritz
   * - Move / Rotate / Scale
     - W / E / R; F5 / F6 / F7 lock X / Y / Z, F8 the plane
   * - Transform Type-In
     - F12
   * - Affect Pivot Only, Center to Object, Reset XForm
     - Insert; quad menu; Object > Transform
   * - Align
     - Alt+A, then pick the target; also in the Utilities tab
   * - Clone
     - Ctrl+V, or Shift+drag (also on a gizmo arrow): Copy, Instance or Reference
   * - Array, Spacing Tool
     - Utilities tab
   * - Snaps, Angle Snap
     - S, A

Modeling
========

.. list-table::
   :header-rows: 1
   :widths: 40 60

   * - Max
     - Moritz
   * - Create panel
     - The Create tab (see :doc:`/modeling/create`)
   * - Convert to Editable Poly
     - Press 1–5, or the quad menu
   * - Sub-object levels 1–5, 6 back
     - The same; Tab also toggles
   * - Edit Poly modifier
     - The same, in the stack (see :doc:`/modeling/edit_poly`)
   * - Smart Extrude
     - The same, and Shift+drag of polygons (see :doc:`/modeling/smart_extrude`)
   * - Soft Selection
     - The Soft Selection rollout (Blender's Proportional Editing), Shift+B
   * - Smoothing groups
     - Modify tab, Polygon level
   * - TurboSmooth, Shell, Bend, FFD …
     - Add Modifier under Max's names (see :doc:`/modeling/modifiers`)

Scene and files
===============

.. list-table::
   :header-rows: 1
   :widths: 40 60

   * - Max
     - Moritz
   * - Scene Explorer
     - The Outliner (see :doc:`/scene/outliner`)
   * - Material Editor
     - M
