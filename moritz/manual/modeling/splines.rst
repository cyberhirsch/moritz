#######
Splines
#######

Shapes from the Create tab (see :doc:`create`) stay parametric until you press **1**, which makes
an editable spline (a Blender curve).

Creating
========

* **Line:** click for corners, drag for curves, click the first point to close.
* **Rectangle, Circle, Ellipse, Arc, NGon, Star, Helix, Donut, Egg …:** drag to create;
  parameters stay in the Modify tab. **Thickness** makes them renderable.
* **Start New Shape** off adds the next shape to the current object.

Editing
=======

In curve Edit Mode, **Spline Tools** holds Fillet, Chamfer, Outline, Break, Trim, Extend and
Connect. In Object Mode, Boolean (Union, Subtraction, Intersection) and Loft (active = path,
selected = shape).

Kept from Blender: handle types, curve Extrude and Bevel (Renderable Spline), the Screw modifier
(Lathe), text objects.
