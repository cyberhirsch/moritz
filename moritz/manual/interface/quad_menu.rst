#########
Quad Menu
#########

Right-click in a viewport opens the quad menu: four quadrants around the cursor, their names in a
band through the middle, as in Max.

* **Display** (top right): hide, unhide, isolate, freeze, viewport lighting and shadows.
* **Transform** (bottom right): Move, Rotate, Scale, Clone, Object Properties, Convert To.
* **Tools 1 / Tools 2** (left): depend on the mode. In Object Mode: Affect Pivot Only, Reset XForm,
  Edit Poly, UVW Map and more. In Edit Poly: the current level's tools (Extrude, Chamfer, Connect,
  Weld, Bridge, Cap, Swift Loop, Cut …) and the sub-object levels, the current one framed.

Entries that cannot run right now are gray. A small square at the outer edge of Extrude, Bevel,
Chamfer, Inset, Connect, Weld and Bridge opens the tool's settings caddy (see
:doc:`/modeling/edit_poly`).

**Reset XForm** in the quad menu runs Blender's Apply > All Transforms.
