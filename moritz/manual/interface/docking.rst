################
Docking and Tabs
################

Moritz's areas dock like panels in Adobe applications:

* **Drag the empty part of an area's header** to move the area. Drop it on an edge of another
  area to dock it there, in the middle to stack it as a tab, or outside the window to tear it off
  into its own window.
* **Tabs** appear next to the editor-type menu when areas are stacked. Click to switch, drag a
  tab to move, dock or tear off just that one, close it with its × button.
* **Duplicate as Tab** in the header's context menu opens a second editor of the same type.

Tabs are stored in the file; Blender opens the file with the active tab of each area.
