# Moritz manual

Source of the Moritz manual, published at <https://cyberhirsch.github.io/moritz/>.

Build it with Sphinx and the Furo theme:

```
pip install sphinx furo
sphinx-build -b html moritz/manual moritz/manual/_build/html
```

The manual covers what Moritz does differently from Blender and links to
[Blender's manual](https://docs.blender.org/manual/en/latest/) for the rest. Text is
CC-BY-SA 4.0, like Blender's manual.
