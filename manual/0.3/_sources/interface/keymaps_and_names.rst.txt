#################
Keymaps and Names
#################

Keymaps
=======

**Preferences > Keymap** offers three presets:

Moritz (default)
   Max's keys where Max has one, Blender's where Max has none. Tab toggles Object / Edit Mode
   besides 1–6, Space maximizes the viewport besides Alt+W, X opens search.

Max
   3ds Max 2026's default keys, as close as Blender allows. Search is on X.

Blender
   Blender's own keymap, unchanged.

In Moritz and Max the middle mouse always navigates, also with a tool active.

Menus and tooltips show Blender's shortcut next to the current one where they differ.

Name schemes
============

**Preferences > Keymap > Names** sets what menus and buttons are called:

Follow Keymap
   The scheme of the chosen keymap.

Blender
   Blender's names.

Max
   Max's names wherever Max has one: Weld for Merge by Distance, Chamfer for Bevel, Attach for
   Join, TurboSmooth for Subdivision Surface, Lathe for Screw.

Moritz
   Max's names, with Blender's name in the tooltip.

The names are a translation of the interface: files, the Python API and F3 search under Blender's
names are unaffected.
